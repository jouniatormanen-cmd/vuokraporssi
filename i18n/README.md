# Vuokrapörssi – kieliversiot

Kielet: suomi (fi), englanti (en) ja ruotsi (sv).

Kaikki käyttöliittymän tekstit, kategoriat, lomakkeet, kirjautuminen, ohjeet ja virheilmoitukset käännetään. Käyttäjien itse kirjoittamat ilmoitukset säilytetään alkuperäiskielellä, kunnes niille toteutetaan erillinen käännöstoiminto.

Tämä on kehityshaara. Julkaistua sivustoa ei muuteta ennen testausta ja hyväksyntää.
